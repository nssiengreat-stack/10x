# 10x Brains – Separation of Mixtures Quiz

Installable Progressive Web App (PWA) built from the supplied HTML quiz.

## Included
- Original 60-question Chemistry quiz and answer review
- 25-minute countdown and built-in calculator
- Installable app manifest and 10x Brains icon
- Service worker for offline use after the first successful load

## Deploy
Upload the contents of this folder to the root of the GitHub repository. The entry page is `index.html`.

For GitHub Pages: open repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.

For Android: open the deployed HTTPS website in Chrome, tap the browser menu, and choose **Install app** or **Add to Home screen**. This creates an installable PWA; it is not a signed APK.
